## 💻 Projeto

Aplicação de gerenciamento de tarefas com persistência local, simulando um fluxo de **Create & Delete** inspirado no conceito de CRUD. O usuário pode adicionar novas tarefas, marcá-las como concluídas com um clique e removê-las individualmente — tudo salvo automaticamente no navegador via **LocalStorage**.

### Funcionalidades

<ul>
  <li>➕ <strong>Criação de tarefas</strong> — adicione novas tarefas de forma rápida e intuitiva.</li>
  <li>✅ <strong>Conclusão com um clique</strong> — ao clicar na tarefa, ela recebe um tachado no texto e um ícone de "concluído" é exibido ao lado, via pseudoelemento CSS <code>::before</code>.</li>
  <li>🗑️ <strong>Remoção de tarefas</strong> — clique no botão <strong>X</strong> para excluir permanentemente a tarefa da lista.</li>
  <li>💾 <strong>Persistência de dados</strong> — todas as tarefas são salvas no LocalStorage, mantendo a lista mesmo após recarregar a página.</li>
</ul>

## 🧠 Aprendizados

Este projeto foi desenvolvido com foco em aprendizado prático. Alguns dos principais conceitos aplicados:

<ul>
  <li>📦 <strong>LocalStorage</strong> — armazenamento e recuperação de dados no navegador, incluindo serialização com <code>JSON.stringify</code> e <code>JSON.parse</code>.</li>
  <li>🧩 <strong>Manipulação de DOM</strong> — criação, atualização e remoção dinâmica de elementos HTML via JavaScript.</li>
  <li>⚠️ <strong>Tratamento de erros</strong> — validações para evitar tarefas vazias e comportamentos inesperados na aplicação.</li>
  <li>🎨 <strong>CSS avançado</strong> — uso de pseudoelementos (<code>::before</code>), customização de scrollbar e estilização de estados interativos.</li>
  <li>🖥️ <strong>UX Design</strong> — atenção à experiência do usuário: feedback visual imediato, interações intuitivas e interface limpa.</li>
  <li>🚀 <strong>Deploy contínuo (CD)</strong> — configuração e publicação automática do projeto via GitHub Pages.</li>
</ul>
